# Материалы вики AstroMine

Здесь хранятся статьи и изображения для вики AstroMine. Исходный код сайта находится отдельно.

Предложите изменение через pull request: измените Markdown-файл в `pages/`, а изображения положите в `images/`. После проверки и принятия в ветку `main` изменения появятся на сайте в течение нескольких минут.

Для новой статьи добавьте запись в `index.json`: уникальный `slug` из строчных латинских букв, цифр и дефисов, название, раздел, описание и путь вида `pages/name.md`. Главная страница использует slug `welcome`.

Используйте изображения PNG, JPEG, WebP или AVIF размером до 2 МБ и вставляйте их как `![Описание](images/example.webp)`. Не добавляйте HTML, SVG, скрипты и секреты. Ссылки должны начинаться с `https://`, `http://`, `/` или `#`. Изображения должны принадлежать проекту или иметь разрешение на публикацию.
